# Flipkart Clone - Basic

This is a minimal Flipkart-like front-end application built with React and Vite. It demonstrates a product listing, product detail modal, and a simple cart with add/remove/update quantity functionalities.

Features
- Product grid
- Product detail modal
- Add to cart
- Cart page with quantity controls and checkout (alert)

Getting started

1. Install dependencies:

   npm install

2. Run development server:

   npm run dev

3. Open the app at the address shown by Vite (usually http://localhost:5173)

Notes
- This is a front-end-only demo using static product data (src/data/products.js).
- Images use Unsplash URLs and require internet access.

You can extend this by adding a backend (Node/Express), authentication, persistent storage, and more advanced UI.
